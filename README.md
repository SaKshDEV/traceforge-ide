# TraceForge IDE

An original, cross-platform IDE built around a programming language
and compiler developed from the ground up.

## Vision

TraceForge aims to combine a customizable code editor, build and run
workflows, and an interactive view of the compilation process.

## Core Goals

- Build a polished IDE with customizable themes.
- Design and implement our own programming language, TraceLang.
- Implement lexical analysis, parsing, semantic analysis, and type checking.
- Generate bytecode and build a virtual machine to execute it.
- Visualize compiler stages through Compiler Lens.
- Add support for other languages through separate toolchain adapters.
- Develop web, desktop, and mobile experiences.
- Maintain automated tests and technical documentation.

## Development Principles

- Understand the purpose of every major dependency.
- Test features and document important architecture decisions.
- Handle compiler errors clearly and consistently.
- Never execute untrusted code directly inside the web API process.
